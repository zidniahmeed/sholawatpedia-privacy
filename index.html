Kebijakan Privasi

Terakhir diperbarui: 22 September 2026

SholawatPedia adalah aplikasi ensiklopedia sholawat berbasis komunitas yang tersedia secara gratis. Halaman ini menjelaskan bagaimana kami mengumpulkan, menggunakan, menyimpan, dan melindungi data pribadi serta data perangkat Anda saat menggunakan aplikasi mobile kami.

Data apa saja yang kami kumpulkan?

Kami hanya mengumpulkan data yang diperlukan untuk menjalankan fitur-fitur utama aplikasi. Berikut kategorinya:

  • Informasi akun – Saat Anda membuat akun kontributor atau pengguna, kami menyimpan nama, alamat email, dan hash kata sandi Anda. Data ini diperlukan untuk autentikasi, menghubungkan sholawat yang di-bookmark, serta menampilkan riwayat kontribusi Anda.
  • Bookmark / perpustakaan offline – Saat Anda mengunduh naskah sholawat untuk dibaca secara offline, kami menyimpan referensi file yang diunduh di perangkat Anda secara lokal. Tidak ada data pribadi yang dikirim ke server kami untuk penyimpanan file offline ini.
  • Tombol donasi – Tombol "Dukung Aplikasi" (ikon hati) tidak mengirimkan data pribadi apa pun. Tombol ini hanya membuka halaman donasi eksternal melalui web-view.
  • Notifikasi – Jika Anda mengaktifkan notifikasi push, kami menyimpan token Firebase Cloud Messaging (FCM) yang terhubung ke akun Anda. Token ini digunakan untuk mengirimkan pemberitahuan status moderasi atau pembaruan kontribusi naskah Anda.
  • Analitik & laporan kerusakan – Melalui Firebase Analytics dan Crashlytics, kami mengumpulkan data penggunaan secara anonim (tampilan layar, ketukan tombol) dan log kerusakan aplikasi. Tidak ada email, nama, atau data lokasi yang disertakan dalam log ini.
  • Informasi perangkat (hanya-baca) – Aplikasi membaca versi sistem operasi perangkat, preferensi bahasa, dan ID instansi yang dibuat secara otomatis. Data ini hanya digunakan untuk keperluan debugging dan memastikan kompatibilitas aplikasi.

Bagaimana kami menggunakan data tersebut?

  • Untuk mengautentikasi Anda dan menjaga sesi login tetap aktif.
  • Untuk menampilkan daftar sholawat yang telah Anda bookmark atau unduh untuk akses offline.
  • Untuk mengirimkan notifikasi push terkait hasil moderasi naskah atau konten baru.
  • Untuk meningkatkan kualitas aplikasi melalui data analitik agregat dan anonim.
  • Untuk mendiagnosis kerusakan dan masalah stabilitas aplikasi.

Berbagi data

Kami tidak pernah menjual, menyewakan, atau membagikan data pribadi Anda kepada pihak ketiga untuk kepentingan periklanan. Satu-satunya layanan eksternal yang menerima data adalah:

  • Google Play Services / Firebase – untuk autentikasi, pengiriman notifikasi push, dan analitik.

Seluruh data yang dikirimkan ke layanan tersebut terbatas pada item-item yang telah dijelaskan di atas.

Penyimpanan dan penghapusan data

  • Data akun (email, nama, hash kata sandi) disimpan hingga Anda menghapus akun Anda melalui halaman Pengaturan di dalam aplikasi.
  • Bookmark dan file offline disimpan secara lokal di perangkat Anda; Anda dapat menghapusnya melalui fitur "Bersihkan Cache" di halaman Akun.
  • Data analitik disimpan sesuai kebijakan retensi default Firebase (hingga 14 bulan).
  • Token notifikasi push akan dihapus secara otomatis saat Anda keluar (logout) dari aplikasi.

Keamanan

Seluruh komunikasi antara aplikasi dan server backend kami menggunakan HTTPS dengan TLS 1.2+. Kata sandi disimpan dalam bentuk hash yang telah diberi salt; kami tidak pernah menyimpan kata sandi dalam bentuk teks biasa. File lokal disimpan di area penyimpanan privat aplikasi yang tidak dapat diakses oleh aplikasi lain tanpa akses root.

Privasi anak-anak

Aplikasi ini ditujukan untuk pengguna dari semua kalangan usia, namun kami tidak secara sadar mengumpulkan data pribadi dari anak-anak di bawah usia 13 tahun. Jika ditemukan data anak di bawah umur, data tersebut akan segera dihapus.

Perubahan kebijakan privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Setiap kali ada perubahan, tanggal "Terakhir diperbarui" di bagian atas halaman ini akan direvisi. Kami menyarankan Anda untuk meninjau halaman ini secara berkala.
